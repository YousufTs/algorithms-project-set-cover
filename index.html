What is Set Cover?

Given a universe U of elements and a collection of subsets, can we select at most k subsets whose union covers all elements?

📡 Example: 6 city districts need Wi-Fi. Each tower covers some districts. Can k towers cover all districts?
The Core Idea
① NP-Complete — hard to find optimal solution, easy to verify one
② Brute-force — tries all 2ⁿ combinations, always optimal but exponential
③ Greedy — always picks the set covering the most uncovered elements
④ Greedy may miss the optimum — guaranteed within ln(n) × OPT
Formal Definition
Input: Universe U, Collection C, integer k
Question: ∃ C' ⊆ C such that
   |C'| ≤ k // at most k sets
   ∪C' = U // covers all of U

Greedy Pseudocode

1. Uncovered = Universe U
2. Selected = {}
3. while Uncovered != empty:
4.   S = set with max overlap
5.   Add S to Selected
6.   Remove S from Uncovered
7. return Selected

NP-Completeness Proof

1. Membership in NP

Certificate: Subset of sets C'.
Verifier: Check if |C'| ≤ k and union covers U. Done in polynomial O(m*n) time.

2. Reduction (VC)

Reduce Vertex Cover to Set Cover.
Edges in G → Universe U.
Vertices in G → Sets in C.

3. Correctness

Forward: k-vertex cover covers all edges.
Backward: k-sets covering U correspond to k vertices touching all edges.
